# Pong

A classic, terminal-based implementation of the arcade game Pong, written in C++. 

## Project Structure
*   **`source/`**: Contains the core C++ source code and game logic.
*   **`libs/`**: Contains the header files used in the project.
*   **`CMakeLists.txt`**: The configuration file for the CMake build system.

## Prerequisites
To build and run this game locally, ensure you have the following installed on your system:
*   A C++ compiler (e.g., GCC or Clang)
*   [CMake](https://cmake.org/) (version 3.10 or higher recommended)
*   Make (or another compatible build tool)

## Build and Compile
1. Clone the repository and navigate into it:
   ```bash
   git clone [https://github.com/yoanevangelu/Pong.git](https://github.com/yoanevangelu/Pong.git)
   cd Pong```

2. Create a build directory and navigate into it:
   ```mkdir build
      cd build```

3. Build the project:
   ```cmake ..```

4. Compile the project:
   ```make```
